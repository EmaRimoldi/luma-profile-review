# Example networking criteria

Status: active

## Goal

Find collaborators working on LLM inference. This is a synthetic demonstration,
not the user's criteria for any real attendee.

## Criteria

| ID | Type | Weight | Criterion | Required evidence |
| --- | --- | --- | --- | --- |
| M1 | must | 0 | Currently works on LLM inference | Explicit current project or role involving LLM inference |
| P1 | prefer | 3 | Is a founder or cofounder | Explicit current founder or cofounder role |
| P2 | prefer | 2 | Is actively seeking collaborators | Explicit statement that the person is seeking collaborators |

## Rules

Missing data is unknown, not no. Event attendance does not demonstrate a skill
or an intention. Past work does not automatically establish a current role.
