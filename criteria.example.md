## Editing

Add one row per criterion. Use `must` with weight 0 for required conditions;
use `prefer` with weight 1–10 for weighted preferences. Give each a unique ID
such as M1 or P1. Escape a pipe inside a cell as `\|`.
Set `Status: active` after defining the criteria. Natural-language context and
rules elsewhere in this document are also sent to the evaluator.

## Evaluation rules

Missing information is unknown, not no. Every yes or no needs a relevant
quote from a source actually read. Contradictory sources need investigation.
Evaluate professional relevance to this goal, with evidence coverage shown
separately from preference points.
